How the signals work

Transparent, explainable, intentionally conservative.

A problem marked solved is not recommended again. Problems you attempted but did not solve are prioritized; needing deeper hints creates a review signal. Missing data is treated as unknown, not weakness. This demo does not measure speed, correctness or retention independently.

Your progress never needs an LLM provider to load. Export and import your data to move it between browsers. Automatic cross-account synchronization requires a secure hosted backend that is not connected here.

Data ownership & portability

Your practice history belongs to you, not to a ChatGPT subscription.

No server account, password, API key, third-party analytics or external script is required. Records stay on this browser's local storage until you export, import, or delete them.
Only exports generated by this app. Max 1 MB. Import replaces local records after confirmation.

Sample records are fictional and cannot be confused with verified submissions. Any existing progress is preserved.

Privacy & limits

A transparent proof of the learning interaction—not a production identity system.

Data is stored with browser localStorage. Clearing browser storage or using another device loses local records unless backed up. This app doesn't send your entries to GitHub, Supermemory or any AI provider. The export contains your notes in readable JSON: keep it private. Only import backups you trust.

For persistent, automatic cross-device sync, the backend must implement verified account linking, transactional storage, consent, revocation and backups. No such claim is made here.
